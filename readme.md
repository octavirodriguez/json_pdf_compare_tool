# Auditor IRS

A tool for auditing PDF and JSON files.

## Description

This project provides functionality to compare pairs of PDF and JSON files.

## Installation

```bash
git clone https://github.com/octavirodriguez/json_pdf_compare_tool.git
cd auditor-irs
```

## Usage

1. Drop your set of files to compare into the data folder.
2. Run 
```bash
source venv/bin/activate
python auditor.py
```
3. A report is created in the **reports** folder
